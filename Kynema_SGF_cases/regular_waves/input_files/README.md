# Unified regular-wave cases

Generated by [generate_cases.py](../generate_cases.py). Both `linear/` and
`stokes5/` contain:

* `mesh_cph1`, `mesh_cph2p5`, `mesh_cph5`, `mesh_cph10`, `mesh_cph20`;
* `aspect_ratio_2`, `aspect_ratio_4`, `aspect_ratio_8`;
* `cfl_0p1`, `cfl_0p2`, `cfl_0p8`, `cfl_1`.

`mesh_cph5` also supplies aspect ratio 1 and CFL 0.5, so no duplicate baseline
runs are needed. All cases record both computed and prescribed-target surfaces
for reflection **and** accuracy. Run from a copy of the complete case directory,
which contains `input.inp`, `static_box.txt` and `case.json`.

See [sweep_summary.csv](sweep_summary.csv) for actual spacings and timesteps, and
[the main README](../README.md) for physics, CFL conventions, cost reductions,
sampling, run/analysis commands and limitations. The old flat reflection and
convergence inputs are replaced by these unified sweeps.
